# GridBill 国网电费

在 iPhone 桌面上看网上国网的余额、用电和阶梯进度。运行在 [Scripting](https://scriptingapp.github.io/) 里，
只在手机上直连国网 App 的接口，不经过任何第三方服务器，也不需要代理、重写或 NAS。

> 这是非官方实现，使用的是非公开接口，可能随时失效，也有被国网风控的可能。只用于你本人的账户，数据以官方 App 为准。
> 目前只在一个北京账号上登录和查询成功过，还有几项没验证，见下面的“验证状态”。

## 装到手机

在装了 Scripting 的 iPhone 上打开这个链接，然后在 App 里确认导入：

**[一键导入 GridBill](https://scripting.fun/import_scripts?urls=%5B%22https%3A%2F%2Fgithub.com%2FYePiXpert%2Fgridbill%2Ftree%2Fmain%2Fscripts%2FGridBill%22%5D)**

链接打不开的话，打开 [Import Scripts](https://scripting.fun/import_scripts)，粘贴这个目录地址生成导入链接：

```text
https://github.com/YePiXpert/gridbill/tree/main/scripts/GridBill
```

只有 `scripts/GridBill` 这个目录会进手机，测试和工具不会。

**更新时不要删除脚本。** 删除脚本会连钥匙串一起清掉，包括登录状态和设备身份，下次登录在国网那边就是一台新设备。正确做法是在 App 的脚本设置里把远程来源设成上面的目录地址，需要更新时手动检查。设置页底部能看到当前版本和远程来源是否已设置。

**不建议打开自动更新。** 谁能往这个仓库推代码，谁就能让代码跑在你手机上，并读到这个脚本的钥匙串。

## 第一次使用

1. 打开脚本，先点“预览小号”“预览中号”，用演示数据看看布局。这一步不联网。
2. 填手机号和密码，点登录。国网要求验证新设备时，界面会出现“发送验证码”。短信只有你点了才会发。也可以切到“验证码登录”，不用密码，但到期后要再登录一次（这条路径还没在真实账号上验证过，见“验证状态”）。
3. 登录成功后脚本会马上查询一次，结果或错误直接显示在账号区。
4. 确认能查到数据之后，再把小组件加到桌面：Scripting 小组件 → 编辑小组件 → 选 GridBill。
5. 阶梯档位和单价默认是北京一户一表、不满 1 千伏的[标准](https://www.beijing.gov.cn/zhengce/gfxwj/202012/W020201201332914812668.pdf)。其他地区或申请过多人口调整的家庭，要改成实际标准。小组件上的本月电费就是按这几个数估算的，以官方账单为准。

建议在 Surge 里加一条规则，让这个域名直连，不要走代理节点：

```text
DOMAIN,csc-service.sgcc.com.cn,DIRECT
```

放多个小组件时，可以在小组件参数里填 `1`、`2`、`3`（第几户）、显示名称或户号尾号。填 `demo` 显示演示数据。

## 它会做什么、不会做什么

**联网：** 只连 `csc-service.sgcc.com.cn:28630`，并拦截所有重定向。这一点集中在 `lib/transport.ts` 一个文件里。

**存储：**

| 内容 | 位置 | 说明 |
|---|---|---|
| 手机号、密码 MD5、登录状态、设备身份、用电数据 | 本脚本的钥匙串 | 按官方文档，其他脚本不能直接读取，不同步 iCloud，不迁移到新设备，删除脚本时一并清除 |
| 显示设置 | 本脚本私有的 Storage | 不含账号信息 |

明文密码不会保存。协议只需要密码的 MD5，所以落地的也只有 MD5。MD5 并不等于安全，别用和其他网站相同的密码。只用验证码登录时，连 MD5 也不会有。

**后台（小组件）的联网规则：**

- 账号被拒、要求短信验证、安全校验失败：只尝试一次，之后完全不再联网，直到你在脚本里处理。
- 登录有效期由国网决定（目前是 15 天），到期后小组件用保存的密码 MD5 自动重新登录，不用手动操作。只用验证码登录时没有密码可用，到期后小组件不联网，只提示你重新登录。
- 自动登录最多 12 小时一次；同一户号查询最多 30 分钟一次；一次运行联网最多 25 秒。
- 绝不自动发短信。
- 密码验证通过后才保存，输错的密码不会被小组件反复拿去试。

**看到“网络连接超时 (RK…),请重试!”时：** 这多半不是网络问题，而是国网的安全校验。RK008 上游有记录，RK007 是在手机上连续登录几次之后遇到的，含义没有公开资料，脚本按同样的方式处理。不要反复重试，确认官方 App 正常后，过几个小时再试一次。换成验证码登录也不一定有用：设备身份没变，国网一样可能拦下。

**数据缺失时：** 缺的就显示 `--`，不会当成 0。某个接口临时报错时保留上次的值，不会用空数据覆盖；所在地区不支持的接口不影响其他数据。

**数据看起来不对时：** 脚本里的“诊断每日数据”会显示国网实际返回的条数、日期和读数，不含账号和户号，可以截图反馈。

## 目录

```text
scripts/GridBill/          脚本本体，装到手机上的就是这个目录
  index.tsx  widget.tsx    两个入口
  ui/                      设置页、小组件界面
  lib/service.ts           什么时候可以联网（最重要的文件）
  lib/vault.ts             本地存储
  lib/transport.ts         唯一的联网出口
  lib/view-model.ts        数据 → 显示内容
  lib/protocol/            国网协议和加密
  NOTICE.md                第三方授权说明
tests/                     离线测试（不会被同步到手机）
tools/preview.cjs          在电脑上预览小组件布局
dts/                       类型声明（占位，手机连接后被官方声明覆盖）
```

## 开发

```bash
npm install
```

```bash
npm run typecheck
```

```bash
npm test
```

```bash
npm run preview
```

测试完全离线。里面有一个模拟的国网网关，真的会解开请求、验证签名、再加密响应。

边改边在手机上看效果，可以用官方的同步工具。电脑和手机要在同一个局域网，Windows 防火墙弹窗时要允许局域网访问：

```bash
npx scripting-cli start
```

手机连接后，App 会把官方的 `.d.ts` 同步到 `dts/`，覆盖这里的占位声明，这时再跑一次类型检查才算完整。这些官方声明不要提交到仓库。

| 类型检查 | 通过，但用的是占位声明，手机连接后换成官方声明要再跑一次 |
| 真实账号登录和查询 | 一个北京账号在手机上成功，但同一晚继续登录时开始被 RK007 拦下，能否恢复待确认 |
